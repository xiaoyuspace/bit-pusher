新建发布任务

使用所选窗口中当前登录的 X 账号发布。

在资源管理器选中视频，按 Ctrl + Shift + C 复制完整路径后粘贴。支持 MP4、MOV、WebM；最终格式、时长和大小限制以 X 页面为准。

保存后进入草稿。点击主界面的「执行选中任务」才会开始上传和自动发布。

重新分配失败任务

使用归档的视频和原文案重新发帖。确认发布成功后会删除这条失败归档。

核实发布结果

请先打开对应账号时间线。确认已发布后粘贴帖子链接，记录为成功。

批量发布

每条文案之间用单独一行 === 分隔，保留条目内换行。只读取文件夹内的视频，不递归子目录。

视频文件名自然排序 → 文案顺序 → 窗口序号从小到大。

新建窗口

选中窗口按序号升序，与代理、token 按行配对。用户名、密码和 2FA 保存在本机，token 用于比特窗口登录。修改代理或 token 会先关闭已打开的对应窗口。

手动检测

可打开比特窗口自行检查，再选择要保存的状态。

迁移窗口凭据

在原电脑导出加密文件，在另一台电脑用同一口令导入。按窗口 ID 匹配，补齐本机尚未保存的代理及账号信息。
